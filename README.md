# 👕 WearFashionAI

WearFashionAI is an AI-powered Virtual Try-On platform that enables users to upload their photo, choose a clothing design or fabric, and generate a realistic image showing how the outfit would look on them.

The project combines a Spring Boot backend with Python-based AI models to provide an intelligent fashion experience.

---

## 🚀 Features

- AI-powered Virtual Try-On
- Person Image Upload
- Clothing Image Upload
- Fabric-Based Clothing Generation
- Realistic AI Image Generation
- Image History Management
- Generated Image Storage
- REST API using Spring Boot
- Python AI Integration
- Modern and Scalable Architecture

## 🔄 Workflow

1. Upload person image
2. Upload clothing or fabric image
3. Select garment type
4. AI processes the images
5. Clothing is generated
6. Virtual Try-On is created
7. Generated image is stored
8. User can view generation history
